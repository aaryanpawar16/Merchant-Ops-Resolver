This turns your tamper-evident chain into something people can use.

Counterfactual "why not?" explainer. Click any decision, such as an escalation, and the system explains why it didn't auto-release. It would list the policy rule that blocked it, the evidence that would have flipped it, and the confidence gap. It already has findings, confidence and conflict, so this is mostly UI plus a small solver.

Live agent-to-agent war room. Show the four agents as a chat or negotiation view. Investigation says "I'm 0.97 sure it's IFSC", Resolution answers "policy check failed, amount over limit", and Coordinator arbitrates. Animate the messages along the graph edges in AgentGraph.tsx.

Human-in-the-loop approval inbox. Escalated cases go to a queue. A reviewer sees the evidence, the proposed action and the draft merchant message, then clicks Approve, Edit or Reject. The decision is written back to memory, so the agents learn from the correction. Add a Slack/email or WhatsApp approval link for mobile.

Self-learning playbooks. Memory currently stores pattern → fix. Extend it so that when a human approves the same fix N times, the system proposes promoting it to an auto-resolve rule. The user approves the promotion, and the rule becomes versioned and diffable. The economics panel would then show cost per case dropping over time.

Anomaly radar. Run a live feed of settlements across all merchants and cluster failures. When 40 merchants suddenly hit IFSC mismatches at the same bank, flag it as a bank-side outage and not 40 separate cases. Show it as a 3D globe or heatmap, since you already have three.

Cinematic case playback. Auto-generate a 30-second animated recap of a run (agents lighting up, evidence flying into the case card, money moving) that can be downloaded as a shareable clip. It extends your OG-image and share-image work.
