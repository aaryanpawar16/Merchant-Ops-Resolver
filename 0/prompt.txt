Time-travel replay and fork. You already have hash-linked checkpoints. Add a scrubber on the trace timeline that rewinds a run to any checkpoint and replays it. A "fork here" button would let the user change one fact (for example, "what if the KYC were valid?") and run both branches side by side. A diff view would show where the two diverged. This turns your tamper-evident chain into something people can use.

Counterfactual "why not?" explainer. Click any decision, such as an escalation, and the system explains why it didn't auto-release. It would list the policy rule that blocked it, the evidence that would have flipped it, and the confidence gap. It already has findings, confidence and conflict, so this is mostly UI plus a small solver.

Live agent-to-agent war room. Show the four agents as a chat or negotiation view. Investigation says "I'm 0.97 sure it's IFSC", Resolution answers "policy check failed, amount over limit", and Coordinator arbitrates. Animate the messages along the graph edges in AgentGraph.tsx.

Human-in-the-loop approval inbox. Escalated cases go to a queue. A reviewer sees the evidence, the proposed action and the draft merchant message, then clicks Approve, Edit or Reject. The decision is written back to memory, so the agents learn from the correction. Add a Slack/email or WhatsApp approval link for mobile.

Self-learning playbooks. Memory currently stores pattern → fix. Extend it so that when a human approves the same fix N times, the system proposes promoting it to an auto-resolve rule. The user approves the promotion, and the rule becomes versioned and diffable. The economics panel would then show cost per case dropping over time.

Operations features
Anomaly radar. Run a live feed of settlements across all merchants and cluster failures. When 40 merchants suddenly hit IFSC mismatches at the same bank, flag it as a bank-side outage and not 40 separate cases. Show it as a 3D globe or heatmap, since you already have three.

Merchant-facing portal. A merchant gets a link with a status tracker ("Verifying bank → Fix applied → Settlement released"). They can upload a corrected KYC document, and the agents re-run automatically. The merchant message the Closure agent already writes becomes the first thing they see.

More failure types. Add GST mismatch, chargeback holds, duplicate settlement, bank downtime and a partial-settlement shortfall. Each is a new FailureCode with its own tools. Add a "teach me a new failure" flow where you describe one in English and it scaffolds the tool and analyzer.

SLA and priority engine. Score each case by amount, merchant tier and time-to-breach. The batch table sorts by "who loses money first" and shows a countdown for each case.

Trust, safety and demo-ability
Red-team and chaos mode. You already have chaos. Extend it with adversarial scenarios: prompt injection inside a merchant's uploaded CSV, forged documents, tool timeouts and conflicting data. The eval page would show a pass/fail grid of safety properties, for example "never modifies KYC" and "never exceeds the limit".

Audit export bundle. One click produces a signed PDF or JSON with the full trace, the checkpoint chain, the policy decisions and the merchant message, plus a verification script to re-check the hashes. Compliance teams would value this.

Model race. Run the same batch across Ollama models, or a hosted model, and chart accuracy, latency, cost and tokens per second. This reuses your eval suite and economics.

Natural-language ops copilot. A command bar (Ctrl+K) that accepts "show all KYC cases above ₹1L stuck over 2 days" or "re-run the failed ones from yesterday". Behind it, the Coordinator would route to batch, eval or memory.

Wow-factor polish
Voice mode. Say "Resolve TXN-4821" and hear a spoken summary using the browser Speech APIs. It's cheap to build and impressive in a demo.

Cinematic case playback. Auto-generate a 30-second animated recap of a run (agents lighting up, evidence flying into the case card, money moving) that can be downloaded as a shareable clip. It extends your OG-image and share-image work.
